CAREKILN / WEBSITE SYSTEM / V1.0

Website brand & motion specification

This is the implementation specification for the approved orange, ink and ivory website direction and Humanist logo. It accompanies an interactive local kit, not a published product. The startup brief governs factual boundaries; the original IA governs content coverage; the later approved visual direction overrides the IA’s earlier forest-green palette proposal.

  • Supplied Concept 26 brief: five exact offers, Medicaid-funded agency COO/staffing director, dispatcher operator, one-state pilot, incumbent scheduling/EVV overlay.
  • CareKiln-Research-and-IA.html: eleven homepage chapters, route families, three synthetic cases, source provenance and evaluation gates.
  • Approved website: CareKiln-Bold-1.png. Orange editorial opening, large black condensed typography, layered ivory workbench UI.
  • Approved logo: option 01 Humanist. Use the delivered SVG master; do not substitute a font or reconstruct the mark.
  • Stripe recordings: Screen Recording 2026-10-18 at 19.24.32.mov and 19.25.38.mov, reviewed through sampled frames and a 0.5-second sequence. Observations concern those supplied recordings, not a claim about Stripe’s current implementation.

3. Asset inventory and usage

assets/brand/ contains outlined master logos and symbols. Use primary on ivory, all ink on orange, orange/ivory on ink. Wordmark minimum width 150px. Keep external clear space equal to half the symbol width. The SVG art has no font dependency. Icons and illustrations use editable paths.

assets/fonts/ contains Anton Regular, Manrope variable, IBM Plex Mono Regular and each SIL Open Font License notice. Fonts are served locally. Current demo uses TTF for portability; WOFF2 subsetting is a future production optimization, preserving applicable license files.

assets/icons/: 36 individual 24×24 SVGs, a sprite and JSON inventory. Stroke 1.75, round cap/join, currentColor. Use 18px inline, 24px control and 32px feature icons, within 44–48px hit targets. Keep status icon and wording together. No social mark is shipped because company profile URLs are unverified.

assets/illustrations/: dispatcher, evidence stack and constraint path. assets/backgrounds/: schedule grid and evidence lines. Static SVGs are editable reusable assets; live HTML/SVG counterparts provide the animations.

4. Color, surfaces and elevation

Brand: persimmon #F06443, ink #141414, ivory #F8F5EE. Paper #FFFEFA; secondary text #605B55; decorative rule #D8D0C5; interactive border #8C8378. Peach #FBD9CD supports the scenario. Status colors use separate semantics and text labels. The supplied contrast report verifies intended small-text pairs mathematically.

Orange fills support ink text. Do not use white body text on orange or orange body text on ivory. Shadows: card 0 12px 36px at 8% ink; floating evidence 0 22px 60px at 16% ink. Radii: controls 6px, cards 10px, dialog 16px. Thin rules and warm flat surfaces dominate; no glassmorphism or multicolor gradients.

Layer order: base 0, evidence card 5, sticky scene 10, navigation 50, dialog 100, toast 110. Dialog uses native top-layer behavior. Hero grid maximum opacity 0.08 per rule with a soft mask. Background line families must not intersect live labels.

5. Typography and alignment

Anton handles the editorial display. H1 128px max desktop, 52–76px mobile; line-height 1.06, tracking −0.018em. H2 72→42px, 1.04. Manrope handles H3 25/1.25 at 750; H4 20/1.35, H5 18/1.4, H6 16/1.4; UI 14/1.4 at 750; body 16–18/1.65; lead 18–24/1.5. IBM Plex Mono handles 11–12px timestamps, labels and source IDs. Data remains actual text.

Use one H1 per page and sequential heading hierarchy. CSS classes control visual scale independently. Headings and body align left. Body maximum 65ch; lead 45ch; reading column 640px. Tables align text left, numeric quantities right, times by tabular figures. Labels use sentence case; uppercase is limited to eyebrows/status chips.

6. Grid and spacing

Max width 1320px. Page gutter clamp(20px, 4.2vw, 64px). Breakpoints 640 / 960 / 1280px. Desktop 12 columns, tablet 8, mobile 4. Intended gaps 24px desktop and 16px mobile. The kit’s demonstration grid has its own visual guides; application layouts use CSS grid/flex.

Spacing scale: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128, 160px. Section padding 96px desktop, 80px tablet, 56px mobile. Heading-to-copy 16px; header-to-content 48/32px. Card inset 28–32/20–24px. Input group gap 20px. Keep 8–12px between icon and label. Align repeated card actions to their lower edge with flex rather than hard-coded content heights.

8. Motion engineering

The prototype uses CSS keyframes, native sticky positioning, IntersectionObserver and the Web Animations API. It has no runtime library or remote CDN dependency. This is a runnable reference implementation; a future React/GSAP implementation should preserve the states and timings rather than substitute different effects.

Durations: 160ms micro-feedback; 220ms controls/dialog; 560ms reveals; up to 800ms scene changes; 70ms stagger for groups of at most four. Ease-out cubic-bezier(.22,1,.36,1); standard cubic-bezier(.2,.65,.3,1). Long paths use linear time. Never stagger paragraphs letter by letter.

Ambient schedule rules drift 24px over 18 seconds while visible, with the same pause controls. Hero loop: 8 seconds, staged evidence arrival and hold; one-hour meter reveals its fixed synthetic fraction. Product loops: 8 seconds each, paused offscreen. Paths: 6 seconds, two markers max. Orbit: 12/18 seconds, fixed text. Figure: 8 seconds with ≤8° arm change. Layer stack: ≤14px secondary travel. Reveal: ≤22px. Page entrance: 280ms / 8px.

Pin one primary chapter only, 300vh on a viewport wider than 960px and taller than 740px. Four stages map to 0–25%, 25–50%, 50–75%, 75–100%. Up-scroll reverses the narrative state, but does not silently undo an explicit simulated decision. Stage controls provide a bypass. Pause freezes loops and removes animated transformations; scrolling still presents discrete readable story states. Reduced motion removes the pin and all nonessential movement.

All animations pause while offscreen or the tab is hidden. The user motion preference is session-only and is not stored. No scroll interception, Lenis, autoplay video, WebGL or forced intro. Motion-heavy full website work still requires real-device performance testing; no Lighthouse score is claimed here.

10. Product and route coverage

Retain /, /products, five /products/visit-* pages, /how-it-works, /preview, /use-cases, /ecosystem, /evaluation, /pilot, /governance, /company, /request-pilot, /contact, /sign-in, /legal/privacy, /legal/terms, /accessibility and branded 404. /pricing can redirect to /pilot. This kit does not implement that full marketing site; it supplies the approved patterns and one product-page specimen.

Every product page: job/user → input → workflow → source evidence → constraints/approval → proposed output → incumbent boundary → failure case → evaluation → FAQ → scoped inquiry. Visit Desk, Visit Review, Visit Proof, Visit Signal and Visit Report remain separate proposed offers, not five live pricing tiers. Lead with one module for the first pilot.

Footer groups mirror the IA. Include LinkedIn/Crunchbase only after real company profiles are verified. Access page must say “No live accounts yet” and route to the synthetic preview; do not collect passwords. Legal notices need an actual entity, owner and collection behavior before launch.

11. Synthetic story and state contract

Tuesday 20 October 2026, Demo County, local illustrative times. DEMO-VIS-001: 09:00–10:00. Absence 08:12. A lacks required skill. B departs 08:50 +25min →09:15, late. C departs 08:30 +20min →08:50, available 08:30–11:00, skill and preference fit. Authorization 08:00–12:00, 3.0h remaining; 1.0h proposed; explicit simulated approval leaves 2.0h hypothetically. Dispatcher Rowan — fictional, decision 08:15. EVV not yet expected. Draft stays unsent.

DEMO-VIS-002: conflicting availability/end-time evidence, freshness unresolved, fictional reviewer Quinn, verify sources. DEMO-VIS-003: 1.0h proposed but 0.5h remains; no feasible candidate, abstain and escalate. No auto-override. The kit implements these three outcomes. The IA’s future ten-row queue requires consistent evidence for all ten records before it is built; partial hero tiles do not claim a full queue or metric total.

Primary evaluation metric: percentage of missed visits with dispatcher-approved feasible coverage before scheduled start versus baseline. Guardrails: authorization breaches and dispatcher minutes; also track unfilled visit count/rate. Record denominator, comparable windows, source, decision-maker role and uncertainty. No performance value is established by this kit.

Readiness: 8 dispatch/COO interviews in one state, 2 replay permissions, confirmed EVV route, 1 paid branch pilot, plus signed data-access/security and human oversight. Worker policy, procurement owner, system of record, named state-rule owner and write permissions must be resolved. Stop/reposition without EVV route and state-rule owner, or if proposed replacements breach travel, skill or hours. No state or domain is declared live.
